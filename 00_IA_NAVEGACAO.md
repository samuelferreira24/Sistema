# 00 — NAVEGAÇÃO PARA IA

## Objetivo
Porta de entrada para qualquer IA, agente ou ferramenta que precise compreender e navegar este repositório histórico do Sistema.

## Regra de navegação
1. Leia este arquivo.
2. Leia `README.md`, se existir na raiz; se não existir, use `00_ESTRUTURA.md`.
3. Leia `00_ESTRUTURA.md`.
4. Para documentação, use `01_documentacao/`.
5. Para runtime Python, use `10_runtime/python/`.
6. Para scripts de execução, use `10_runtime/shell/`.
7. Para interface, use `20_interface/`.
8. Para integração nativa, use `40_integracao/`.
9. Para material preservado, use `99_arquivo/`.

Não alterar, mover ou excluir arquivos sem verificar dependências. A organização física deve preservar o conteúdo e a rastreabilidade histórica.
