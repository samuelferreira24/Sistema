# Estrutura do repositório Sistema

Organização funcional do repositório histórico.

- `01_documentacao/`: documentação e memória.
- `10_runtime/`: runtime histórico executável, separado por linguagem.
- `20_interface/`: interface web histórica.
- `40_integracao/`: integrações específicas.
- `99_arquivo/`: material legado preservado.

A numeração organiza por função e não representa uma ordem obrigatória de execução.

O conteúdo histórico foi preservado; esta organização não declara que os componentes históricos constituem capacidades atuais do Projeto Absoluto.
