# Estrutura do repositório Sistema

Este repositório preserva o **Sistema Absoluto histórico**.

## Camadas

- `01_documentacao/` — documentação histórica e contratos de operação.
- `10_runtime/` — núcleo executável histórico, separado por linguagem/camada.
- `20_interface/` — interface web/PWA e ativos visuais históricos.
- `40_integracao/` — integrações Android preservadas do sistema histórico.
- `99_arquivo/` — material legado preservado como fonte histórica, sem função operacional atual.

## Regra de preservação

A organização física não reescreve a história do projeto. Conteúdo histórico é preservado; código legado não é reinterpretado como capacidade atual do Projeto Absoluto.

Arquivos executáveis foram classificados por função somente quando isso não exigia alterar seu conteúdo. Material antigo cuja função é apenas histórica permanece em `99_arquivo/`.

## Estado

Este repositório é **fonte histórica**. O runtime atual do Projeto Absoluto não deve ser inferido automaticamente a partir dele.
