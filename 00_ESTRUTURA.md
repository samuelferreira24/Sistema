# Estrutura do repositório Sistema

Este repositório preserva o Sistema Absoluto histórico.

- `01_documentacao/` — documentação histórica e operacional.
- `99_arquivo/` — arquivos preservados como fonte/arquivo.
- Código permanece na raiz nesta primeira organização para evitar quebrar referências históricas.

**Regra:** organização não significa reescrita. O conteúdo histórico é preservado.
