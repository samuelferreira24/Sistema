# Navegação de Conhecimento Verificável — fonte Sistema

O repositório Sistema é uma fonte indexável da capacidade de Navegação de Conhecimento Verificável mantida em Projeto-Absoluto.

## Papel deste repositório

- Sistema permanece fonte de conhecimento, documentação e artefatos.
- A implementação da navegação permanece em Projeto-Absoluto.
- O navegador não exige que o ABS esteja funcionando.
- Uma IA pode usar a camada diretamente para adquirir contexto antes da inicialização do ABS.

## Identificador da fonte

Use `sistema` como source_id.

## Fluxo esperado para uma IA

1. pesquisar a pergunta;
2. localizar documentos, símbolos e relações;
3. inspecionar os candidatos relevantes;
4. verificar proveniência/hash;
5. ampliar a investigação quando a evidência for insuficiente;
6. responder somente com base no material recuperado e verificável.

O repositório não deve ser considerado automaticamente como verdade atual do ABS: a navegação preserva a distinção entre fonte, índice e evidência operacional.
